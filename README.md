# 모아모아베이커리: 오늘의 빵집 (v3 재미 업그레이드)

모바일 웹(세로 화면 우선, 390x844 기준) 빵 만들기 게임입니다. 서버·로그인·결제가 없는 정적 사이트이고, 저장은 브라우저 localStorage(키 `moamoa-save-v1`)만 씁니다. 빌드 단계가 없습니다.

## 실행 방법

1. 가장 간단한 방법: `index.html` 파일을 브라우저로 바로 엽니다. (정적 서버 없이 동작합니다. 일부 브라우저는 `file://` 에서 저장소를 제한할 수 있어요. 그럴 땐 2번을 쓰세요.)
2. 로컬 서버:

```bash
cd game-v1
python3 -m http.server 8765
# 브라우저에서 http://localhost:8765/index.html 열기
```

폰에서 확인하려면 같은 와이파이에서 `http://<컴퓨터 주소>:8765/index.html` 로 접속합니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 껍데기. 모든 화면은 `js/app.js` 가 `#app` 안에 그립니다(한 파일 앱). |
| `css/style.css` | 팔레트(Gemini 스펙 추정값)·390x844 세로 기준 스타일. 터치 영역 48px 이상, 패널 불투명, 한국어 단어 단위 줄바꿈. |
| `js/data.js` | 메뉴·재료 카드·손님(좋아하는 빵 `fav`)·대사·채점 말·안내 문구. **새 메뉴는 여기에 데이터만 추가하면 됩니다.** 모카소금빵은 데이터가 있지만 `open:false` 이고, 출석 스탬프 3개로 `app.js` 의 `UNLOCKS` 가 연다. |
| `js/app.js` | 코어 루프, 미니 동작 3종, 채점, 인내심·팁·목표·출석·상점, 저장, 날짜 시드, 효과음, SVG 그림. |
| `VERIFY_v1.md` | v1 검증 결과(그대로 보존). |
| `VERIFY_v2.md` | 손보기 후 검증 결과(통과/실패/미확인). |
| `VERIFY_v3.md` | v3 재미 업그레이드 검증 결과·수치(통과/실패/미확인). |

### 화면 (app.js 안의 함수)

타이틀(`showTitle`, 간판) → 매장 홈(`showHome`, 코인·단골 마음·오늘의 목표·출석 스탬프) → Day 소개(`showDayStart`, 오늘 올 손님 3명) → 주문(`showOrder`, 인내심 바 시작) → 재료 고르기(`showIngredients`) → 미니 동작(`showMake`: 치대기·성형·굽기, 끝날 때마다 말+별) → 채점·손님 반응·팁(`showResult`, 단계별 말과 별) → 하루 정산(`showSettle`, 별·팁 요약·별 도장·내일의 빵). 별도로 빵 도감(`showDex`), 작은 상점(`showShop`), 설정·안내(`showSettings`). '시작하기 전에' 안내 모달은 없고, 안내 한 줄('실제 레시피가 아니에요'·알레르기)은 도감 하단과 설정에만 있습니다.

### 새 메뉴 추가하기

`js/data.js` 의 `BREADS` 에서 잠긴 항목(`open: false`)을 열린 항목으로 바꾸고 아래 필드를 채웁니다.

```js
{ id: 'rice-scone', cat: 'baked', name: '쌀스콘·에그스콘', open: true,
  desc: '한 줄 설명', wish: ['식감으로 말하는 주문 문장'], hint: '메뉴 이름',
  actions: ['shape', 'bake'],          // knead / shape / bake 중 2~3개
  shapeKind: 'stretch',                // shape 가 있을 때: stretch(늘리기) 또는 pan(틀에 넣기)
  art: 'roll',                         // saltbread / loaf / roll
  ingredients: [{ id, icon, name, why }],   // 재료 카드 3~4장 + 이유 한 줄
  decoy: { id, icon, name, why } }     // 어울리지 않는 재료 카드 1장(눌러도 안내만 나와요)
```

코드 수정은 필요 없습니다. 재료 문구에는 양·온도·시간 같은 숫자를 쓰지 않습니다.

### 장면 (배경 그림 함수)

`sceneTitle`(차양·우드 바닥) / `sceneHome`(진열장·창·구석 트리) / `sceneOrder`(카운터 위 진열장) / `sceneBake`(타일·스테인리스 작업대, 재료·제작 화면) / `sceneSoft`(정산·도감·설정·Day 소개). 가운데 구역은 UI가 올라오는 자리라 비워 둡니다.

## v3 변경 내역

- **명칭**: 게임 안의 '2호점' 표기를 모두 뺐습니다(매장명 `모아모아베이커리`, 주소는 그대로).
- **시작 전 안내 제거**: `빵집 열기`·`이어서 하기`를 누르면 바로 홈·주문 화면으로 갑니다.
- **손님 인내심**: 주문 화면부터 결과 직전까지 바가 서서히 줄어듭니다. 빨리 내줄수록 팁이 많고, 바닥나도 게임오버 없이 별 하나·팁만 줄어듭니다. 하루 1회 `🍪 시식 권유`로 일부 회복합니다.
- **단계별 정확도**: 치대기·성형·굽기가 끝난 직후 말과 별(★)을 보여 주고, 채점 화면에도 단계마다 한 줄씩 별이 붙습니다.
- **일일 목표**: 날짜로 정해지는 목표 1개(6개 목록). 달성하면 보너스 코인.
- **출석 스탬프·해금**: 하루 1개. 3개가 모이면 **모카소금빵**이 도감에서 열리고 플레이할 수 있습니다(저장 상태로 관리).
- **좋아하는 빵·단골 손님**: 손님마다 좋아하는 빵이 있고(💛), 서빙하면 보너스 팁. 하루 마지막 단골 손님은 팁이 많고 Day 3부터 엄격합니다.
- **팁·코인·작은 상점**: 코인은 localStorage 에 저장. 상점은 `빠른 오븐`(굽기 구간 넓힘)·`편한 카운터`(인내심 천천히) 2가지.
- **난이도 곡선**: Day 1~2 넉넉 → Day 3 단골 손님 엄격·굽기 구간 조금 좁게 → Day 5 인내심 빨리 줄어듦 → Day 7 러시(연달아 오는 대신 팁 많음). 실패 화면 없음.
- 홈·정산의 기존 `스탬프`(오늘의 빵 별 3개)는 새 출석 스탬프와 헷갈리지 않게 `별 도장`으로 이름을 바꿨습니다.
- 저장 키 `moamoa-save-v1`·구조는 그대로입니다. 옛 저장 파일은 새 필드(코인·업그레이드·스탬프·목표·해금)를 기본값으로 채워 이어집니다.
- `tools/scan_forbidden.sh` 의 [4]번에서 `코인`을 뺐습니다(게임 코인이 정식 장치가 됨). 나머지는 그대로.

## v2 변경 내역

- 미니 동작: 치대기 4바퀴·`찰지게` 구간 눈금·손가락 궤적, 성형 손잡이 48px 이상·과도하게 늘리면 경고, 굽기 왕복 5.2초·구간 넓힘·`지금 노릇해요!` 실시간 표시. 치대기·굽기 미터는 화면 회전·크기 변경 때 위치를 다시 잽니다.
- 채점: 평균 문구를 없애고 재료·반죽·성형·굽기 말을 각각 보여 줍니다.
- 화면: Day 소개가 실제 첫 손님과 같은 손님을 보여 줍니다. 정산에 별 요약·스탬프·내일의 빵 미리보기(금액 없음). 도감 잠긴 빵에 실루엣. 재료 카드에 종류 태그.
- 그림: 손님에 팔·다리, 아이는 엄마 옆에 서 있음. 진열장 빵 모양·굽기 정도를 다르게.
- 결과 카드 이미지: 손님 문장이 길어도 폭을 재서 줄바꿈합니다.
- 크리스마스 장식은 11~1월 기본 켜짐, 설정에서 끌 수 있습니다. 홈에서는 구석의 작은 트리입니다(상시·계절 한정은 아직 정하지 않아 토글 유지).

## 게임 규칙 요약

- 하루 = 손님 3명(쉬운 주문 2명 + 단골 1명). 하루 끝에 정산. 중간에 나가면 그 손님까지 저장되고 타이틀·홈의 `이어서 하기`로 이어집니다(이어하면 그 손님의 인내심은 새로 시작).
- 실제 날짜(YYYY-MM-DD, 기기 날짜 기준)를 시드로 오늘의 빵·단골 손님·일일 목표를 정합니다. 오늘의 빵을 별 3개로 만들면 별 도장 1개, 게임을 연 날마다 출석 스탬프 1개.
- 점수는 `단골 마음` 게이지로 쌓이고, 팁은 코인(게임 안 가상 재화, 실제 돈과 무관)으로 쌓입니다. 실패·게임 오버가 없습니다.
- 팁 = 별 × 3 × (0.5 + 남은 인내심), 단골 손님·러시는 각각 1.5배, 좋아하는 빵이면 +6. 수치와 곡선은 `VERIFY_v3.md` 참고.
- 공유는 정산 화면의 결과 카드 이미지(PNG) 저장만 지원합니다(빵 이름·별·손님 한 줄·매장명·주소만 들어가요).

## 이미지·사진

외부 이미지·AI 이미지를 쓰지 않았습니다. 매장·빵·손님은 CSS와 인라인 SVG 도형으로 그렸습니다. 매장 실사는 사용 동의가 확인되기 전이라 쓰지 않습니다. 나중에 실사로 바꾸려면 `js/data.js` 의 `PHOTOS` 에 `'scene-home'`, `'scene-order'`, `'scene-bake'` 키로 이미지 경로를 넣으면 해당 배경 그림이 사진으로 교체됩니다.

## 폰트·효과음 라이선스

- 폰트: 번들하지 않았습니다. 기기에 있는 글꼴(`Pretendard` → `Noto Sans KR` → `Apple SD Gothic Neo` → `Malgun Gothic` → 시스템 기본)을 순서대로 씁니다. 외부 폰트 파일·웹폰트 요청이 없어 별도 라이선스 의무가 없습니다.
- 효과음: 외부 음원 파일이 없습니다. 브라우저의 Web Audio API로 코드에서 직접 합성한 짧은 소리(톱니·사인파·잡음)라서 저작권 있는 음원을 쓰지 않았습니다. BGM은 없습니다. 설정과 타이틀·화면 상단에서 소리를 켜고 끌 수 있습니다.
- 이모지(🌾 🧈 등): 기기 기본 글꼴의 이모지를 그대로 보여 줍니다(별도 파일 없음).

## 매장 확인이 필요한 것

- 재료 카드 문구(특히 쌀식빵의 재료 구성)는 설계안입니다. 매장 확인 후 확정해야 합니다.
- 영업시간·전화번호는 게임에 넣지 않았습니다(주소만 표기).
